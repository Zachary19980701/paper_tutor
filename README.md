# Paper Tutor
一篇技术论文真正的价值，往往藏在动机的转折处、方法的假设里、公式的近似中、图表的对比间，以及实验没有说出口的边界上。但现实中，读论文常常变成：
- 快速扫一遍 abstract 和 introduction，然后假装读过了；
- 卡在一个公式上，不知道每个符号代表什么、为什么这样定义；
- 看完实验表格，却说不出作者到底证明了什么、没证明什么；
- 把 AI 生成的一段总结当成理解，但一合上就什么都想不起来；
- 分不清哪些是论文原话，哪些是二手解读，哪些是自己脑补的推导。
- 与此同时，大语言模型已经可以"总结"任何论文，但总结不等于带读。一次性摘要会抹掉论证链条、跳过概念瓶颈、掩盖假设与近似，也不会在你卡住的时候停下来问你一句"这里要不要深入数学"。
paper-tutor 就是为这个问题设计的：把 LLM 从"论文摘要器"变成"一步步带读的AI助手"。

## 如何使用
这是一个Hermes原生的skill文档，并且理论兼容所有使用md文档的agent，并且可以放在网页对话中，让网页的AI也能够按照paper tutor的思路进行工作。

### 在Agent中进行使用
适用于 Hermes 或其他支持加载 SKILL.md 的 agent 环境。

克隆仓库：
```bash
# 下载仓库中的SKILL.md
将 SKILL.md 放入 skills 目录
```

```bash
mkdir -p ~/.hermes/skills/paper-tutor
cp paper-tutor/SKILL.md ~/.hermes/skills/paper-tutor/SKILL.md
```
具体路径取决于你的运行时配置。

如果运行时支持从仓库加载 skill，也可以直接指向本仓库。

触发 skill，并给出一篇论文：

```text
请用 paper-tutor 带我读这篇论文：https://arxiv.org/abs/XXXX.XXXXX
skill 会先给出简短导览，然后询问阅读模式：
```

```text
全文精读
核心精读
指定部分
快速理解
```

### 在网页 对话中进行使用
如果你在用 ChatGPT、Claude、Gemini 等网页对话，不需要安装任何东西。

打开本仓库的 SKILL.md，复制全文。

在新对话中粘贴 SKILL.md 内容，并加一句：

```text
从现在起，请严格按照这份 SKILL.md 的规范，作为 paper-tutor 带我读论文。
然后给出论文链接或粘贴论文内容：
```

```text
请带我读这篇论文
```
之后就可以用自然语言控制阅读过程

```text
核心精读
只看方法
深入数学
结合代码
跳到实验
讲简单点
回顾
```

>提示：网页对话的上下文长度有限。如果论文很长，可以按章节分段粘贴，或先让 skill 做导览，再针对具体章节深入。

### 常用指令
| 指令	<br>   | 作用                  |
| --------- | ------------------- |
| 全文精读	<br> | 按论文论证顺序完整阅读         |
| 核心精读	<br> | 聚焦核心方法、关键公式、关键图表和局限 |
| 指定部分	<br> | 只读指定章节或主题           |
| 快速理解	<br> | 高层解释整篇论文            |
| 只看方法	<br> | 跳转到方法部分             |
| 只讲公式	<br> | 进入公式导师模式            |
| 深入数学	<br> | 增加推导严谨度             |
| 结合代码	<br> | 映射到实现               |
| 跳到实验	<br> | 跳到实验评估              |
| 讲简单点	<br> | 减少数学，增加直觉           |
| 回顾        | 总结当前阅读状态            |
